# 아트 에셋 (assets/)

이 폴더에 PNG를 넣으면 게임의 도트 아트를 **자동으로 대체**합니다.
파일이 없으면 기존 절차적 도트 스프라이트로 **자동 폴백**하므로, 하나씩 교체해도 게임은 항상 정상 동작합니다.

교체 지점은 `block_maze_td_v4.html` 상단의 `ART` / `ART_TILES` 객체 한 곳뿐입니다.
파일명을 바꾸고 싶으면 그 객체의 값만 수정하세요.

## 규칙 / 팁

- **투명 배경 PNG** 로 저장하세요(바닥 타일 floor_a/floor_b 는 불투명 정사각형).
- 캐릭터/오브젝트는 **가운데 정렬**, 여백 최소화. 한 칸은 34px이고 스프라이트는 약 2배(≈24–28px 높이)로 표시됩니다.
- 원본 해상도는 표시 크기보다 커도 됩니다 — 엔진이 **높이를 기준으로 자동 축소**하고, PNG는 부드럽게(스무딩) 그립니다. (도트 폴백은 픽셀 그대로)
- 정면/약간 위에서 본 시점(top-down TD)에 맞춰 그리면 자연스럽습니다.
- 바닥 타일은 상하좌우로 **타일링(이음매 없음)** 되도록 만들면 가장 깔끔합니다.

## 교체 방법

1. 위 파일명으로 PNG를 이 폴더에 저장
2. 브라우저에서 `block_maze_td_v4.html` 새로고침 → 끝

생성 프롬프트는 상위 폴더의 `ART_PROMPTS.md` 참고.

## 애니메이션 (스프라이트 시트)

정지 이미지 대신 **가로로 이어붙인 프레임 시트**를 넣으면 애니메이션됩니다.

- 파일명은 그대로(`enemy_grunt.png` 등), 대신 가로로 프레임을 N칸 이어 붙입니다.
- `block_maze_td_v4.html`의 `ART`에서 해당 키의 `frames`를 N으로, 재생속도는 `fps`로 설정.
- `frames:1`(기본)이면 단일 정지 이미지로 처리 → 기존 PNG 그대로 호환.

예시(4프레임 걷기, 8fps):
```js
grunt: { src:'enemy_grunt.png', frames:4, fps:8 },
```

시트 규격:
- 각 프레임은 **같은 크기의 정사각 칸**, 가로로 나란히. 전체 이미지 = (프레임폭 × N) 가로.
- 예: 프레임당 64×64, 4프레임이면 최종 이미지 256×64.
- 높이 기준으로 화면 표시 크기가 정해지므로, 모든 프레임 높이는 동일해야 합니다.
- 프레임 순서 = 재생 순서(왼→오), 마지막 다음엔 처음으로 루프.

바닥 타일(floor_a/b)은 애니메이션 대상이 아닙니다(정적 타일).
